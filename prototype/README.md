# PASS_PW 假資料 UI 原型

這是用來複核 [PLAN.md](../PLAN.md) 第二版流程的互動介面，**不是可以保存密碼的產品**。Go 標準庫只提供本機靜態預覽，尚未建立 Wails 桌面程式。

不要輸入真實帳密。此原型沒有加密、DPAPI、真實寄信、網站登入、MCP、OS 隔離或真正的備份檔；所有帳密都是公開假資料，狀態只在前端記憶體，重新整理即清空。不要將本預覽器暴露到網際網路。

## 啟動

需要 Go 1.25 或更新版本；本次用 Go 1.25.6。無第三方 Go 套件。

在 PowerShell 執行：

```powershell
Set-Location 'D:\PASS_PW\prototype'
go run .
```

開啟 [本機預覽](http://127.0.0.1:8716/)。僅監聽 IPv4 loopback；不修改防火牆。停止時在該終端按 Ctrl+C。若 8716 已被占用，先確認是否已有本原型在執行，不要終止不明程序。

靜態資源用 Go embed 打包；修改 HTML／CSS／JavaScript 後需重啟 Go 程序，再重新整理頁面。這會清除當次假資料。

## 演練資料

| 用途 | 假資料 |
| --- | --- |
| 主密碼 | 首次設定時自訂（至少 12 字元），建議 `DemoMaster!2026` |
| 示範備份檔密碼 | `DemoBackup!2026`，或本次演練匯出備份時設定的密碼 |
| Email 驗證碼 | 每次隨機產生，顯示在驗證碼對話框的「示範信箱」 |
| 項目 | 3 個網站登入（work／reading／design.example.com）、1 個 Wi-Fi 密碼、1 則安全備註 |
| AI 連線 | 預設已配對一個示範 Codex |
| AI 預設授權時間 | 示範工作平台預設 4 小時，其它網站 30 分鐘（可在編輯中改） |

示範信箱同時列出舊驗證碼及狀態（有效、已被新碼取代、已作廢等），可用來測試舊碼失效。示範寄送器不會連網或寄信。

「複製」會把假密碼寫入**你電腦的剪貼簿**，30 秒後清空剪貼簿（原型不判斷內容是否已被你換掉）。

## 演練控制台

頁面底部「演練控制台」模擬原型無法真的發生的事件；正式產品不會有這些按鈕。

| 群組 | 按鈕 |
| --- | --- |
| AI 代理 | AI 提出登入要求、核准逾時、AI 取得頁面快照（看過濾後內容）、AI 要求填入帳密、AI 在假冒網址要求填入、AI 對密碼欄位輸入、AI 授權到期 |
| 時間與系統 | 閒置自動鎖定、Windows 鎖定、電腦休眠、本人驗證逾 60 秒、重新首次設定 |
| Email | 切換寄信失敗、過了一小時（重設寄送次數）、結束 Email 暫停 |

驗證碼對話框內另有「模擬驗證碼過期」「模擬 60 秒已過」。

## 建議查看順序

1. 首次設定：主密碼 → 綁定 Email（輸入示範信箱的驗證碼）→ 匯出備份或「稍後再說」。
2. 密碼清單：類型篩選、搜尋空結果；新增網站登入（試 HTTP 會被拒、用「產生密碼」）。
3. 查看 Wi-Fi 密碼：60 秒內直接顯示；按「本人驗證逾 60 秒」後再顯示需驗證；可改寄 Email 驗證碼；顯示 30 秒後自動遮罩；複製。
4. AI：提出要求 → 拒絕；再要求 → 允許這次 → 完成網站驗證 → 頁面快照、填入、假冒網址、密碼欄位輸入。
5. 鎖定：閒置鎖定（已登入工作保留）→ 鎖定中 AI 要求與填入都回 vault_locked → 解鎖；「允許此網站」選時間（或自訂分鐘數）後再要求會自動允許；在 AI 代理頁按「延長」；勾選「Windows 鎖定時保留」的已登入工作在 Windows 鎖定後保留，其它停止；電腦休眠全部停止。
6. Email 規則：錯 5 次作廢、作廢後正確碼也無效、過期、第 6 封達上限、連續 3 組作廢暫停、寄信失敗改用主密碼、忘記主密碼用 Email 重設。
7. 設定：匯出備份（一定重新驗證）、CSV 匯入（重複略過）、從備份還原（另建）、新增／撤銷 AI 連線、停用 Email。

## 範圍限制

- 30 秒遮罩、60 秒免驗證是真實計時；AI 授權的到期時刻也用真實時鐘計算並每 5 秒檢查，可用「AI 授權到期」立即結束；2 分鐘核准逾時、10 分鐘驗證碼效期、15 分鐘暫停、每小時寄送上限使用演練控制模擬。
- 驗證碼以明文存在前端記憶體；正式版只存 HMAC。並發驗證、主程式重啟後失效、時鐘調整不在原型範圍。
- 主密碼錯誤的等待時間（1、2、4… 秒）是真實計時，但重新整理即重設。
- 備份、還原、CSV 匯入只演示畫面，沒有讀寫檔案。
- 「登入中→需要網站驗證→已登入」是固定的模擬順序，不連接任何網站或 Agent；頁面快照是寫死的示範內容，用來說明過濾規則。
- 示範配對與「未隔離」標示不是實際的 Windows 帳號檢查。
